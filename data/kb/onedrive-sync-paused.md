# OneDrive sync paused or stuck

## Fix
1. Click the OneDrive cloud icon and choose **Resume syncing**.
2. If files show a red cross, check the file name has no unsupported characters and the path is under 400 characters.
3. If sync is still stuck, choose **Settings > Account > Unlink this PC/Mac** and sign in again. Files already synced stay on the device.
