# Keyboard types the wrong symbols

## Fix
If @ and " are swapped, the layout is set to US instead of UK. On Windows open **Settings > Time & language > Language & region** and set the keyboard to "United Kingdom". On a Mac open **System Settings > Keyboard > Input Sources** and add "British".
