# Local administrator rights

## Policy
The help desk does not grant local administrator or Domain Admin rights. Requests for elevated access go through the access portal with manager approval and a security review. Approved access is time-limited.

## What to do instead
Most software can be installed from the software portal without admin rights. If you need something that is not in the portal, raise a software request.
