# ABLATION: what breaks without each Clocked endpoint

All 32 locked eval cases ([eval/cases.jsonl](eval/cases.jsonl)) replayed from their recordings with one endpoint's answer neutralised at a time. **0 credits, no key**: `pnpm ablate` reproduces this file byte for byte. Generated by [`scripts/ablate.ts`](scripts/ablate.ts); outcomes come from FixProof's own policy, harms from the eval scorer ([`lib/eval/score.ts`](lib/eval/score.ts)).

Method note: steps after the neutralised one replay the answers they gave on the real inputs, so this measures what each gate stops on these tickets; it is not a fresh live run without the endpoint.
