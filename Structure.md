# Structure: FixProof

```
fixproof/
  app/
    layout.tsx, page.tsx, globals.css   # shell, intake + proof trail page, design tokens
    api/triage/route.ts                 # SSE orchestrator endpoint (Node runtime)
    api/health/route.ts                 # mode + whether a key is configured
  components/
    ui/                                 # shadcn/ui primitives (generated, edit sparingly)
    IntakeForm, ProofTrail, StepCard, EvidenceText, ClaimChips,
    ConflictCard, ScriptGate, HandoffCard, OutcomeBanner, CreditMeter
  lib/
    utils.ts                            # cn() helper
    clocked/client.ts                   # fetch transport, idempotency, backoff, credits, limiter
    clocked/types.ts                    # request/response types for all 9 endpoints + pipeline
    clocked/replay.ts                   # fixture lookup and replay transport
    agent/run.ts                        # orchestrator
    agent/steps/*.ts                    # screen, understand, retrieve, reconcile, draft, prove, fixGate, handoff
    agent/policy.ts                     # pure outcome bands
    kb/load.ts, kb/index.ts             # parse markdown KB, minisearch BM25, neighbors
    text/offsets.ts                     # code-point-safe slicing and span removal
    ratelimit.ts                        # live-mode caps
  data/kb/*.md  data/personas.ts  data/scenarios.ts
  fixtures/<scenario>/<step>.json       # recorded or synthetic Clocked responses
  scripts/record-fixtures.ts            # re-record fixtures with a real key
  tests/*.test.ts                       # vitest
  e2e/smoke.spec.ts                     # playwright
  docs/                                 # architecture diagram, screenshots
  PRD.md Techspec.md Appflow.md Schema.md ImplementationPlan.md Tracker.md Rules.md Security.md Structure.md
  README.md CLOCKED.md .env.example LICENSE
```

## Boundaries
- Only `lib/clocked/*` talks to Clocked. Steps call the client, never `fetch` directly.
- `lib/agent/policy.ts` is pure (no I/O) so outcome rules are unit-tested.
- Components never import from `lib/clocked` (server only).
- The API key is read only in `lib/clocked/client.ts`.

## Config
`next.config.ts`, `tsconfig.json`, `eslint.config.mjs`, `postcss.config.mjs`, `components.json` (shadcn), `vitest.config.ts`, `.env.example`.

## Generated
`.next/`, `next-env.d.ts`, `node_modules/` (ignored). `components/ui/*` is generated by shadcn then owned by the repo.

## Adapter files
None yet. If an agent rules file is added (AGENTS.md, CLAUDE.md), it points to Rules.md as the source of truth.
